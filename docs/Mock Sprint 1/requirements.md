## Overview
This document defines the requirements for the Team Page and the restyling of the Login Page, as part of the Task 2 mock sprint.

## Login Page
- Scope is **styling only** — no changes to authentication logic, validation, or session handling.
- Existing functionality must remain fully intact after restyling.

## Team Page
Required fields per team member:
- Team name
- Project name
- Member photo
- Member name
- Member role
- About-us blurb

## Edge Cases Identified
- **Missing headshot:** one team member does not currently have a photo — design needs a placeholder-avatar treatment.
- **Long blurbs:** two team members have longer blurbs than others — design must not assume a one-line blurb; text should wrap or expand gracefully rather than being cut off.
